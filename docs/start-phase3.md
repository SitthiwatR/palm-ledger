ผู้ใช้ทดสอบและรับงาน Phase 1–2 แล้ว ให้เริ่ม implement Phase 3: รายจ่ายทั่วไป ค่าแรงรายวัน และปุ๋ย ตาม acceptance criteria ในแผนเดิม

บันทึกไว้ว่า OCR/data extraction ปัจจุบันให้ผลไม่ดี ผู้ใช้ให้ปิด Phase 2 และย้ายการปรับวิธีอ่านบิลไป Phase 10 ไม่ต้องแก้ OCR หรือเปลี่ยน provider ในงานนี้ ยังไม่มีการเลือกบริการใหม่หรืออนุมัติค่าใช้จ่าย คงทางกรอก/แก้เองไว้ ส่วนการตรวจ iPhone/Safari จริงและเป้าหมายจบใน 1 นาทียังคงค้าง ไม่ถือว่าผ่านแล้ว

ใช้ค่าแรงรายวัน/รายน้ำหนักผูกบิลและชื่อ/อัตราที่จำไว้ซึ่งมีแล้วเป็นฐาน ป้องกันการนับรายจ่ายซ้ำ เพิ่มรายจ่ายแยกบิล ปุ๋ยตามที่ใช้จริง และจ่ายครบ/บางส่วน/ยังไม่จ่ายพร้อมประวัติการจ่ายครั้งแรกแบบ atomic โดยให้รายจ่ายลดสุทธิครั้งเดียว

รักษา UI/Three.js บัญชี รูป และข้อมูล production เดิม ใช้ฐานทดสอบแยก เมื่อทดสอบผ่าน ให้อัปเดตแผนและ handoff, commit/push และตรวจ deployment บน Vercel ของ commit ล่าสุดจนเป็น Ready
